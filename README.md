# 🛡️ Cybersecurity - Relatório de Aulas

Este repositório tem como objetivo documentar os principais conteúdos e práticas abordados durante a disciplina de **Cybersecurity**, seguindo o cronograma de aulas proposto em sala.  

  


## 🎯 Objetivo
- Consolidar o conhecimento adquirido ao longo da disciplina.  
- Criar um material de referência organizado e de fácil acesso.  
- Registrar as principais vulnerabilidades, ataques e ferramentas apresentadas pelo professor.  
- Demonstrar, por meio de relatórios, a compreensão e aplicação prática de cada assunto.  

---

## 📚 Estrutura do Repositório
O repositório está organizado conforme as aulas ministradas, incluindo desde conceitos introdutórios até ataques e técnicas avançadas:

1. **Preparação do ambiente de testes**  
2. **Introdução**  
3. **SQL Injection**  
4. **SQLmap**  
5. **Cross Site Scripting (XSS)**  
6. **BeEF**  
7. **Command Injection**  
8. **Commix**  
9. **LFI (Local File Inclusion)**  
10. **RFI (Remote File Inclusion)**  
11. **Denial of Service (DoS)**  
12. **Sniffers e Spoofing**  
13. **Brute Force**  
14. **Testes automatizados**  

---

## 📝 Proposta
Este projeto não tem caráter ofensivo ou de incentivo a atividades ilegais.  
O foco é **puramente acadêmico e educacional**, voltado para o aprendizado em **cibersegurança**, boas práticas e conscientização sobre ataques e defesas em sistemas computacionais.
